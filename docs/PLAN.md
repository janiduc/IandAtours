# I&A Tours web app plan

1. ✅ **Foundation and tour catalog.** React + TypeScript frontend, FastAPI backend, PostgreSQL.
   Tour packages, vehicle fleet, about/contact pages, USD/LKR price switch and WhatsApp contact.
2. ✅ **Bookings, payments and admin area.** Online booking with card payment (USD for foreign visitors,
   LKR for locals), likely via PayHere. Admin area for tours, guides, vehicles and bookings.
3. ✅ **Multi-agent AI assistant (free models).** A trip-planner agent for travellers and a staff agent that
   drafts replies and helps manage bookings, with staff approval. Model-agnostic: Ollama with open models
   (Llama, Qwen, Gemma) in development, a free-tier hosted API such as Groq or Gemini in production.
4. **Polish and launch.** Mobile polish, SEO and deployment.
